# 🖥️ RISC-V Assembly — Computer Organization

A collection of Assembly programming exercises developed for the **Computer Organization** course, exploring low-level programming concepts using the **RISC-V instruction set architecture (ISA)**.

## ⚙️ Architecture and Environment

The programs are written in **RISC-V Assembly**, using 32-bit integer operations and instructions from the **RV32I** base instruction set, along with the **M extension** for multiplication.

- **Architecture:** RISC-V (RV32IM-style code)
- **Programming Language:** RISC-V Assembly

The exercises explore register manipulation, memory addressing, arithmetic instructions, conditional branches, loops, and low-level data processing.

## 📁 Exercises

- **`binario`** — Manual conversion of RISC-V Assembly instructions into their binary machine-code representations.
- **`menorvetor.asm`** — Finds the position of the smallest element in an integer array.
- **`matriz.asm`** — Sorts the elements of a square matrix using Bubble Sort and calculates its determinant for 2×2 or 3×3 matrices.
- **`raizquadrada.asm`** — Calculates the integer square root of a number using successive subtraction of odd numbers, distinguishing exact and approximate results.
- **`final.asm`** — A Battleship game implemented entirely in RISC-V Assembly.

## 🚢 Final Project — Battleship

The final assignment consists of a console-based **Battleship game**, implemented entirely in Assembly.

It uses a **10×10 grid** and provides a menu that allows the player to:

- Fire shots at specific coordinates.
- View the ship positions and the player's board.
- Receive feedback on hits, misses, and sunken ships.
- Restart the game.

## 🎓 Academic Context

Developed as part of the **Computer Science** undergraduate program, for the **Computer Organization** course.
